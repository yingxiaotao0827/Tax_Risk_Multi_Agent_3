# 2025.04 - 2025.08 项目排期

## 2025.04 需求与技术验证

- 明确六类核心诊断任务：进项异常、销项收入差异、税负率异常、供应商集中、费用跨期、政策适配。
- 验证 Qwen2.5-14B-Instruct 在税务规则问答、结构化输出、工具调用提示上的可行性。
- 选型 LangChain v0.3、Milvus 2.5、SQLite/PostgreSQL、FastAPI。

## 2025.05 数据与工具链建设

- 建立企业财报、发票、申报表、法规库的数据模型。
- 实现只读 SQL、财务指标计算、法规检索、证据链生成工具。
- 建立基础评测集和输出格式校验。

## 2025.06 Multi-Agent 闭环

- 落地稽查主 Agent 的 ReAct 推理流程。
- 实现监督审核 Agent，对证据完整性、法规引用、结论一致性打分。
- 加入工具预算、异常降级和人工复核队列。

## 2025.07 报告与可观测性

- 生成企业税务健康体检报告，输出 Markdown/API JSON。
- 增加结构化日志、审计字段、风险图表数据。
- 针对六类任务调参并做回归评测。

## 2025.08 试运行与优化

- 上线试运行，收集人工复核反馈。
- 优化政策匹配准确率、报告格式规范率和误报处理。
- 固化部署文档、应急策略和面试可演示样例。
