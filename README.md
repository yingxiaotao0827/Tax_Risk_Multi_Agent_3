# Tax_Risk_Multi_Agent_3
核心技术： Multi-Agent 架构、ReAct 范式、Function Calling（工具链集成）、结构化推理链、Human-in-the-Loop（人工复核） 
项目描述：基于企业财报、发票流向及税务法规库，构建多 Agent 协同的税务风险智能诊断系统。通过模拟税务专家“发现风险、补充证据、交叉验证、复核审查”的完整流程，自动生成高可靠性的《企业税务健康体检报告》，精准识别潜在财税风险。
1、【双 Agent 质量控制机制】 创新设计并落地 “稽查主 Agent + 监督审核 Agent” 的双层架构。主 Agent 基于 ReAct 范式 进行风险假设与动态推理，监督 Agent 在关键节点进行数据口径与结论一致性审查，从架构层面保障诊断结果的严谨性。
2、【异构工具箱与证据链】 深度集成只读 SQL、财务指标计算、税务规则检索等工具链（Tool Use）。驱动 Agent 自动联动发票流向与财务指标，将推理判定过程沉淀为可追溯的结构化证据链，并自动转化为可视化图表。
3、【异常降级与人工兜底】 设计 Human-in-the-Loop（人工复核） 安全闭环机制。针对数据缺失、逻辑冲突或工具超预算等边缘场景（Edge Cases），系统自动打标并降级流转至人工复核层。通过规则校验、引用溯源与人工复核机制，降低错误结论直接出具风险，保障报告输出可追溯、可复核。
